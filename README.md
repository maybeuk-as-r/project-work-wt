# Smart Attendance Management System — Phase 2

## Project
Web Technology Project — UI Forms and Validation

Based on the Phase 1 synopsis:
- Smart Attendance Management System
- Roles: Admin, Teacher, Student
- Attendance sessions and attendance records
- Optional face verification
- Class-wise and student-wise reporting

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- No Node.js, no backend, no frameworks required

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Use the navigation to open Login, Registration and dashboards.

## Pages
- `index.html` — responsive home page
- `pages/login.html` — login UI + validation
- `pages/register.html` — registration UI + validation
- `pages/admin-dashboard.html` — administrator dashboard
- `pages/teacher-dashboard.html` — teacher dashboard
- `pages/student-dashboard.html` — student dashboard
- `pages/classes.html` — class table + add-class form
- `pages/attendance.html` — attendance session + status controls
- `pages/reports.html` — reports table + CSV export
- `pages/profile.html` — profile form

## Phase 2 interactions
- Responsive navigation
- Mobile sidebar
- HTML5 input types and required fields
- JavaScript client-side validation
- Password show/hide
- Registration password matching
- Modal forms
- Attendance status buttons
- Face verification demo interaction
- Search/filter table
- CSV report export
- Save/submit feedback

All data is static/demo data because this submission intentionally avoids backend complexity for Phase 2.
